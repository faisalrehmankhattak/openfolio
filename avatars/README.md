The upstream repository supplies an MIT license, retained in
`LICENSE-readyplayerme.txt`. The GLB retains its Ready Player Me copyright.
This is the repository's example asset, not a claim about licensing of arbitrary
avatars created through the Ready Player Me service.

Docker and `scripts/fetch-demo-avatar.sh` fetch the same unmodified model.
The model includes a humanoid skeleton and ARKit facial shapes. Openfolio uses
approximate ARKit mixtures for audio visemes absent from this sample; native
Oculus visemes are preserved when a custom avatar already provides them.
